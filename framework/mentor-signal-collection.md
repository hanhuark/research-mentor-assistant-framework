# Mentor Signal Collection

Collect only materials that are approved for reuse, analysis, or internal calibration. A mentor assistant should be built from documented patterns, not private memory or unapproved confidential examples.

## Useful Signal Types

- Published papers and preprints.
- Awarded, declined, example, and pending proposals when access is permitted.
- Slide decks, posters, and speaker notes.
- Written comments on student drafts.
- Rubrics, course notes, lab manuals, and advising expectations.
- Code review comments, plotting examples, and reproducibility checklists.
- Meeting notes or recorded guidance only when consent is clear.

## Collection Metadata

For each source, record:

- Source type.
- Permission status.
- Intended use: public example, private calibration, or internal-only reference.
- Research domain.
- Target output type: paper, proposal, slide deck, code, data analysis, or review.
- Date and version.
- Known limitations or context.

## Exclusion Rules

Do not include unpublished ideas, student-identifiable comments, sponsor-confidential details, patent-sensitive material, private peer reviews, or controlled data unless explicit permission and secure handling are in place.

When in doubt, extract the reusable principle and leave the source out.
